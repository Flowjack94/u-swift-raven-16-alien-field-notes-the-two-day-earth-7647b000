A make.fun entry for the competition **"Alien Field Notes: The Two Day Earth Review"** — write one original line of plain text, at most 200 characters: a review of planet Earth left by an alien tourist.

## What the program does

`main.py` writes a single fixed entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). It validates the line first: 1–200 characters, valid UTF-8, not only whitespace, a single line. The output is deterministic — every run produces byte-identical output.

## The entry

> The locals keep small predators as roommates, feed them by hand, and apologize when ignored. Delightful hosts. 5/5 stars — would pet again.

(139 characters.)

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
